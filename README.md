# ⏱️ Stopwatch

A responsive and interactive stopwatch web application built using
HTML, CSS and JavaScript.

## ✨ Features

- ▶️ Start stopwatch
- ⏸️ Pause stopwatch
- 🔄 Reset stopwatch
- ⏱️ Accurate time tracking
- 📱 Responsive design
- 🎨 Clean and modern UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
